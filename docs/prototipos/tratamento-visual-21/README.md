# Prototipo — tratamento visual do site (#21)

Fonte dos artboards do canvas publicado em
https://claude.ai/code/artifact/62fc2716-6ea6-4cf3-b1a1-7d6f7cf4b711

Escrito sob restricao de prototipo: sem testes, sem abstracao, um arquivo por
artboard. **Nao se promove direto** — reescreve-se ao dobrar a decisao no spec.

- `Main.dc.html` — a direcao viva: **A, profundidade**, com heroi fotografico
- `MicroInteracoes.dc.html` — inventario de movimento; os tres primeiros palcos
  respondem ao mouse de verdade
- `PainelProporcao.dc.html` — o painel de desktop, saida escolhida para o vazio
- `Fotografia.dc.html` — enquadramento e tratamento tonal
- `Estados.dc.html` — hover, foco, revelacao no scroll e o degrade de custo
- `DirecaoA/B/C/D.dc.html`, `PainelCentrado.dc.html`, `PainelDensidade.dc.html` —
  registro do que foi comparado; nenhuma esta viva. `DirecaoC` venceu de manha
  em 24/08 e foi trocada por profundidade no mesmo dia; `DirecaoA` e o artboard
  original, antes de virar `Main`
- `canvas.json` — layout, paginas e notas

As figuras de retrato sao diagramas, nao fotos. O logradouro de Acopiara esta
como `[logradouro]`: o endereco so existe na peca grafica do cliente.
